EM Bookshop Website

Frontend bookstore website built using HTML, CSS, and JavaScript.

Originally created in 2024 as part of early web development practice and later uploaded to GitHub as part of my portfolio.

The project includes:
• a homepage and library page
• interactive payment modal
• form validation using JavaScript
• responsive styling and layout
• multi-page website structure

The project was mainly focused on developing frontend functionality and improving interactive user experience through JavaScript event handling and DOM manipulation.
